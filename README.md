# Muhammad Jawad — Personal Portfolio

A modern, responsive and interactive personal portfolio website built with **React.js** and **Vite**.

The portfolio presents my skills, projects, experience and contact information through a clean, modern interface with smooth animations and responsive layouts.

## ✨ Features

* 🎨 Modern and professional portfolio design
* ⚡ React + Vite based application
* 📱 Fully responsive design
* 🌙 Dark mode support
* ✨ Smooth animations and transitions
* 🎬 Animated loading screen
* 🖼️ Interactive profile/hero section
* 💼 Projects showcase
* 🛠️ Skills and services section
* 💬 Testimonials section
* 📩 Contact form
* 🔄 Animated skills/services marquee
* 📜 Smooth scrolling
* 🎯 Scroll reveal animations
* 🖱️ Interactive hover effects
* 📐 Mobile, tablet and desktop responsive layouts

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd PORTFOLIO
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
